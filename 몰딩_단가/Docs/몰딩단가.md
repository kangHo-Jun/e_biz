## 1. 사용 파일 구조

### 📄 시트21.csv (입력 데이터)
- **크기**: 37행 × 8열 (A~H)
- **역할**: 생성할 제품 목록
- **H열**: 템플릿명 (예: `평몰딩 30*9`, `평몰딩 40*9` ...)

| 열 | 내용 | 예시 |
|----|------|------|
| A | 대대분류 | 목자재/철물 |
| B | 대분류 | 목자재/철물 |

## 2. New시트 생성 규칙

### 전체 구조
- **헤더**: 1행 (컬럼명)
- 시트21의 37개 제품 × 229행 = **총 8,524행** (헤더 포함 8,525행)
- 제품 순서대로 **하나의 시트에 세로 배열**
  - 1번째 제품 (평몰딩 30*9): 행2 ~ 행230
  - 2번째 제품 (평몰딩 40*9): 행231 ~ 행459
  - N번째 제품: 행 `2 + (N-1)*229` ~ 행 `230 + (N-1)*229`

---

### 규칙 1: A2:H2 채우기
**대상**: 각 블록의 **첫 번째 행(행2)만**

**방법**: 시트21의 해당 제품 행(A~H) 값을 그대로 복사

```
New시트 A2 = 시트21 A열 (목자재/철물)
New시트 B2 = 시트21 B열 (목자재/철물)
New시트 C2 = 시트21 C열 (목자재)
New시트 D2 = 시트21 D열 (몰딩)
New시트 E2 = 시트21 E열 (영림)
New시트 F2 = 시트21 F열 (빈칸)
New시트 G2 = 시트21 G열 (평몰딩 30*9) ← 대산 제품명
New시트 H2 = 시트21 H열 (평몰딩 30*9) ← 제품명 = 템플릿명
```

---

### 규칙 2: 템플릿명 정의
```
템플릿명 = 시트21 H열 값 = New시트 H2 값
예) 평몰딩 30*9
```

---

### 규칙 3: W2 입력 (기본단가)
**대상**: 각 블록의 **첫 번째 행(W2)만** / W3:W32는 입력하지 않음

**조회 방법**:
1. 기준가격 B열(col1)에서 **템플릿명** 검색
2. 일치하는 행의 **D열(col3)** 값 가져오기

```
예) 템플릿명 = "평몰딩 30*9"
    기준가격 B열에서 "평몰딩 30*9" 찾기 → index8 행
    D열(col3) = 2,420
    → W2 = 2,420
```

---

### 규칙 4: Z33 이후 입력 (색상 추가금)
**대상**: 각 블록의 **33행(헤더 제외 32번째)부터 229행까지**
- Z2:Z32 (헤더 제외 1~31번째) → **입력하지 않음** (원본 "-" 유지)
- Z33 (헤더 제외 32번째) 부터 → 아래 방법으로 입력

> ※ 행 번호 기준: 헤더=1행, 첫 데이터=2행, Z33=33행(헤더 제외하면 32번째 데이터)

**YL등급 → 차액 컬럼 매핑:**

| 템플릿 O열 값 | 기준가격 차액 컬럼 | Python col | 평몰딩30*9 예시 |
|-------------|----------------|-----------|--------------|
| YL-1 | (없음, W2에만 입력) | - | - |
| YL-2 | N열 차액 | 13 | 550 |
| YL-3 | P열 차액 | 15 | 550 |
| YL-4 | R열 차액 | 17 | 770 |
| YL-5 | T열 차액 | 19 | 1,210 |
| YL-6 | V열 차액 | 21 | 1,980 |

**조회 방법**:
1. 기준가격 B열(col1)에서 **템플릿명** 검색
2. 템플릿 해당 행의 **O열 값** (YL등급) 확인
3. 위 매핑표에서 해당 YL의 **차액 컬럼** 값 가져오기
4. **출력 형식**: `O열값-차액값` (예: `YL-2-550`, `YL-4-770`)

```
예) 블록내 index32행, O열 = "YL-2"
    기준가격에서 "평몰딩 30*9" 찾기 → N열(차액) = 550
    → Z33 = "YL-2-550"

예) 블록내 index172행, O열 = "YL-4"
    기준가격에서 "평몰딩 30*9" 찾기 → R열(차액) = 770
    → 해당 Z셀 = "YL-4-770"
```

## 3. 전체 처리 흐름 요약

```
시트21 (37개 제품)
  ↓ 각 제품마다 반복
  ├─ 템플릿명 = H열 값
  ├─ 기준가격에서 템플릿명 검색
  │    ├─ D열 → W2 (기본단가)
  │    └─ N/P/R/T/V열 차액 → Z33이후 (YL등급별 추가금)
  └─ 229행 블록 생성
       ├─ 행1: A2:H2 = 시트21 A~H 복사
       ├─ 행1: W2 = 기본단가 (YL-1 가격)
       ├─ 행1~31: Z열 = "-" (원본 유지)
       └─ 행33~229: Z열 = "YL-N-차액" 형식 입력
```
