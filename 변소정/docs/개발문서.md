# 쇼핑몰 배차노트 자동화 시스템 개발 문서

## 1. 프로젝트 개요
쇼핑몰(오늘의 집 등)에서 수신되는 배차 메시지를 구글 시트에 자동으로 파싱하여 입력하는 시스템입니다. 슬랙에서 전달되는 특정 형식의 메시지를 분석하여 필요한 정보(날짜, 금액, 주문번호, 품목 등)를 정해진 열에 자동으로 채워줍니다.

## 2. 완성된 기능
- **GAS(Google Apps Script) 파싱 자동화**
  - 구글 시트 **A열**에 메시지 텍스트가 입력되면 트리거가 작동하여 자동으로 데이터 추출
  - 추출된 데이터를 **E/F/J/L/M열**에 각각 자동 입력

## 3. 파싱 규칙

### 입력 텍스트 형식
- 메시지는 반드시 다음 기호 중 하나로 시작해야 합니다:
  - `:large_blue_circle:`, `:star:`, `🔵`, `⭐`, `🌟`, `★`, `☆`
- 예시: `🔵 2026.04.20(월) [오늘의집] 주문번호 1234567 - [품목명] 결제금액: 150,000 ...`

### 각 열 추출 규칙 표
| 출력 열 | 항목 | 추출 규칙 (Regex/Logic) |
|:---:|:---:|:---|
| **E열** | 날짜 | `YYYY-MM-DD` 형식의 날짜 (점/슬래시 구분자 포함) |
| **F열** | 요일 | `(월)`, `(화)` 등 괄호 안의 요일 텍스트 |
| **J열** | 금액 | `결제금액:` 뒤의 숫자 (콤마 제거 후 숫자만 입력) |
| **L열** | 주문번호 | `주문번호` 뒤에 오는 연속된 숫자 |
| **M열** | 품목명 | 첫 번째 `-` 기호 이후부터 "시공/납품" 문구 전까지의 텍스트 |

## 4. GAS 코드 전체 (`Code.js`)

```javascript
/**
 * 1. 수동 테스트용 함수
 */
function debugManualTest() {
  const range = SpreadsheetApp.getActiveRange();
  console.log('[TEST] 선택된 셀: ' + range.getA1Notation());
  parseAColumn({ range: range });
}

/**
 * 2. 트리거 등록 함수
 */
function installTrigger() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  ScriptApp.getProjectTriggers().forEach(t => ScriptApp.deleteTrigger(t));
  ScriptApp.newTrigger('parseAColumn')
    .forSpreadsheet(ss)
    .onEdit()
    .create();
  console.log('트리거 설치 완료: ' + new Date().toLocaleString());
}

/**
 * 3. 실제 실행 함수 (추출 로직)
 */
function parseAColumn(e) {
  if (!e || !e.range) return;
  
  const range = e.range;
  const sheet = range.getSheet();
  const row = range.getRow();
  const col = range.getColumn();
  
  const displayValue = range.getDisplayValue();
  
  if (col !== 1) return;

  const text = displayValue.trim();
  
  // 대상 기호 체크
  const isTarget = text.includes(':large_blue_circle:') || 
                   text.includes(':star:') ||
                   text.includes('🔵') || 
                   text.includes('⭐') || 
                   text.includes('🌟') ||
                   text.includes('★') ||
                   text.includes('☆');
                   
  if (!isTarget) return;

  // 파싱 로직
  let item = '';
  const itemMatch = text.match(/-(.+?)(\r?\n시공\/납품|\r?\n-)/s);
  if (itemMatch) {
    item = itemMatch[1].trim();
  } else {
    const firstLine = text.split('\n')[0];
    const hIdx = firstLine.indexOf('-');
    if (hIdx !== -1) item = firstLine.substring(hIdx+1).trim();
  }

  let price = '';
  const priceMatch = text.match(/결제금액:\s*([\d,]+)/);
  if (priceMatch) price = priceMatch[1].replace(/,/g, '');

  let date = '';
  const dateMatch = text.match(/(\d{4}[-./]\d{2}[-./]\d{2})/);
  if (dateMatch) date = dateMatch[1].replace(/[./]/g, '-');

  let day = '';
  const dayMatch = text.match(/\(([월화수목금토일])\)/);
  if (dayMatch) day = dayMatch[1];

  let order = '';
  const orderMatch = text.match(/주문번호\s*(\d+)/);
  if (orderMatch) order = orderMatch[1];

  try {
    if (date) sheet.getRange(row, 5).setValue(date);
    if (day)  sheet.getRange(row, 6).setValue(day);
    if (price) sheet.getRange(row, 10).setValue(price);
    if (order) sheet.getRange(row, 12).setNumberFormat('@').setValue(order);
    if (item)  sheet.getRange(row, 13).setValue(item);
    console.log('[DEBUG] 파싱 완료: ' + item);
  } catch (err) {
    console.error('[DEBUG] 입력 에러: ' + err.message);
  }
}
```

## 5. 적용 방법
1. 구글 시트 상단 메뉴의 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. 위 **GAS 코드 전체** 내용을 복사하여 `Code.gs` 에 붙여넣고 저장합니다.
3. 함수 선택 메뉴에서 `installTrigger`를 선택하고 **실행**합니다.
4. 권한 승인 팝업이 뜨면 모두 승인합니다. (이후 A열 입력 시 자동 실행됩니다.)

## 6. 슬랙 자동화 시도 및 포기 이유
초기에는 파이썬(Playwright)을 이용해 슬랙 메시지를 실시간으로 읽어 구글 시트에 자동으로 넣어주는 완전 자동화를 시도했으나, 다음과 같은 기술적 한계로 인해 중단되었습니다.

- **is_restricted 오류**: 워크스페이스 보안 정책상 외부 앱(슬랙 봇) 설치가 제한됨.
- **Playwright 차단**: 슬랙 웹 접속 시 자동화 도구(헤드리스 브라우저 등)를 감지하여 접근을 차단함.
- **d 쿠키(세션) 유지 문제**: 슬랙의 보안 강화로 인해 로그인 세션 쿠키를 외부에서 유지하기가 매우 까다로움.
- **결론**: 안정적인 운영을 위해 **수동 복사 → GAS 자동 파싱** 방식을 유지하기로 결정함.

## 7. 현재 운영 방법
1. 슬랙 채널에 올라온 배차 메시지를 복사합니다.
2. 구글 시트의 **A열** 빈 셀에 붙여넣습니다.
3. 등록된 **GAS 트리거**가 즉시 작동하여 E, F, J, L, M열의 정보를 자동으로 채웁니다.

## 8. 향후 계획
- **오늘의 집 담당자 협의**: 해당 슬랙 채널에 정식 봇(App) 추가 권한을 요청할 예정입니다.
- **완전 자동화**: 봇 권한 승인 시, API를 통해 메시지를 직접 수신하여 사람의 개입 없이 24시간 자동 입력되는 시스템으로 전환 가능합니다.
